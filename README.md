# Welcome to your Fantasy basketball free agent assistant

## Stack
- HONO JS framework
  - For server implementation
- SQLite and Kysley
  - Will be used to store and sync all league data from Yahoo
    - Manual syncs initially
- Tailwind CSS for styling
- Pylon Graphql

## Development
1. Run local server: `npm run dev`.
2. Set up Ngrok for https `ngrok http http://localhost:3000` and copy URL. Should be something similar to *https://26xx-xxx-114-xxx-59.ngrok-free.app*.
3. Set up Yahoo app OAuth callback using URL generated by previous step.
4. Login by auth/login route.
5. Restart server to seed DB.
6. Go to /graphql route to explore data.
